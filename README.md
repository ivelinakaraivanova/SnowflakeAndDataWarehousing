# SoftUniSnowflakeAndDataWarehousing
My solutions to SoftUni Snowflake and Data Warehousing course problems

## Exam project: Retail Data Pipeline (Python, S3, Snowflake, Airflow)

Hybrid ETL + ELT pipeline for retail sales data. Python (pandas) extracts data from Amazon S3, validates it with Pandera, transforms it and saves it back to S3. Snowflake builds a star schema and materialized views for reporting. Airflow orchestrates the pipeline.
